# 🌐 Multi-Page Blog Website

A modern, clean, and responsive Multi-Page Blog Website developed using HTML5 and CSS3. This website provides an attractive platform to explore blogs, read articles, and find contact information.

## 🚀 Live Demo

🔗 [View Live Website]("https://madihakhan612.github.io/Multi-Page-Blog-Website/")

## ✨ Features

- 🏠 Home Page
- 📝 Blog Page
- 📖 Article Page
- 📩 Contact Page
- 📱 Fully Responsive Design
- 💻 Desktop, Tablet & Mobile Compatibility
- 🎨 Modern and Clean UI
- 🖼️ Attractive Images
- 🔗 Social Media Icons
- 🔤 Google Fonts
- 📐 CSS Media Queries
- 🌈 Tailwind CSS Integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- Tailwind CSS
- Google Fonts
- SVG Icons

## ⚙️ How to Run Locally

1. Clone this repository:

```bash
git clone ["https://github.com/Madihakhan612/Multi-Page-Blog-Website"]
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Navigate through the website pages.
